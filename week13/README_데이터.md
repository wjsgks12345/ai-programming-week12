## 데이터

### 데이터 출처
- AI협업프로그래밍 13주차 실습 배포 자료
- scores_2026.csv

### 데이터 크기
- 원본 데이터: 114행, 5열
- 정제 후 데이터: 100행, 5열

### 열 설명
- 학번: 학생의 고유 번호
- 이름: 학생의 이름
- 반: 학생이 속한 반
- 과목: 성적을 평가한 과목
- 점수: 학생의 과목별 성적

### 데이터 정제 방법
- 점수가 비어 있는 행 6개 삭제
- 완전히 동일한 중복 행 4개 삭제
- 반과 과목의 앞뒤 공백 제거
- 0~100 범위를 벗어난 행 4개 삭제

### 빈칸 처리 및 이유
- 점수가 비어 있는 행 6개를 삭제하였다.
- 빈칸을 0점이나 평균값으로 대체하면 실제 성적과 달라져 통계 분석 결과에 영향을 줄 수 있기 때문이다.
- 따라서 분석 결과의 정확성과 신뢰성을 높이기 위해 점수가 비어 있는 행을 제거하였다.
